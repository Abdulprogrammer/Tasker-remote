How does this work?

Your phone and PC never connect directly. Both talk to a free message relay (ntfy.sh) using a shared topic name that acts like a password.

When you tap Send, the task is published to that topic. Your PC runs a small daemon (in the background) that polls the topic; when it sees a task, it resolves aliases (e.g. start-canvix) and runs the command. If the PC is off, the task waits; the daemon picks it up next boot. If a task fails, the daemon retries every minute until it succeeds.

Status notifications (PC online, ✅ done, ⚠️ failed) arrive in the ntfy app — install it from your phone's app store for push alerts.
